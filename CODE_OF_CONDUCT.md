# Community conduct

Help make this project welcoming and useful. Discuss ideas and code respectfully, give actionable feedback, and allow people to learn. Harassment, threats, discrimination, personal attacks, and publishing another person's private information are not acceptable.

These expectations apply to this repository's issues, pull requests, and other project spaces. Maintainers may edit or remove harmful content, close disruptive discussions, and restrict participation when necessary. Decisions should be proportionate and explained when doing so does not expose private information.

For a public problem, use GitHub's **Report content** action. For harassment or private safety concerns, use [GitHub's reporting process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). Never post private account data in an issue. Software vulnerabilities should follow [SECURITY.md](SECURITY.md).

中文：请尊重参与者，针对代码和观点给出具体反馈。不得骚扰、威胁、歧视、人身攻击或泄露他人隐私。维护者可以处理有害内容和持续干扰；涉及私人信息的举报请使用 GitHub 的举报入口，软件漏洞请按安全策略提交。
