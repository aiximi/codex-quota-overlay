# 2.1.1 · 浮窗可见性与自动恢复

发布标签：`v2.1.1`。同时提供 macOS Apple Silicon、Intel 和 Windows x64 安装包，历史版本继续保留。

[下载中心](https://github.com/aiximi/codex-quota-overlay/blob/main/DOWNLOADS.md) · [全部版本与变化](https://github.com/aiximi/codex-quota-overlay/blob/main/docs/VERSIONS.md) · [此版本发布文件](https://github.com/aiximi/codex-quota-overlay/releases/tag/v2.1.1)

## 更新内容

- 修复 macOS 浮窗进程仍在运行、Codex 已在前台但浮窗没有出现在当前桌面的情况。原生助手按浮窗的窗口 ID 和进程核对实际可见性，不再仅依赖 Electron 的可见标志；发现不一致时重新显示，保持 Codex 输入焦点。
- 在系统唤醒、解锁后重启窗口跟随，先清除旧位置，再根据当前前台窗口恢复显示，避免沿用休眠前的窗口状态。
- 修复窗口跟随助手累计失败几次后永久停止的问题。macOS 和 Windows 均持续自动重连，失败时逐步退避到最长 30 秒，恢复稳定后回到短重试间隔。
- 菜单栏/托盘和设置中的“恢复浮层位置”同时重新启动窗口跟随。只会在重新确认 Codex 窗口有效时恢复显示。
- 保留 2.1.0 的官方额度、订阅及重置明细同步，以及 Windows 的点击、自定义安装盘符和便携版支持；本次没有改变重置兑换逻辑。

## 安装与迁移

先通过菜单栏/托盘退出旧浮窗，再安装本系统的新版本。macOS 替换 Applications 中的应用；Windows 运行新安装包，或退出便携版后替换 EXE。切换到 Codex 后显示浮窗，切换到其他应用或最小化 Codex 后隐藏。

设置和已有重置操作记录保留。拉取 Git 源码不会自动替换安装的应用；本项目目前没有应用自动更新器。

## 验证范围

新增 macOS 原生窗口回归：人为制造“Electron 报告可见、窗口服务器报告隐藏”的状态，验证自动恢复、前后台隐藏策略和不抢焦点。新增跟随助手连续失败、退避、恢复和退出测试。现有离线交互检查继续覆盖展开/收缩、设置保存、过期数据和禁用真实重置。

发布流水线分别在 macOS arm64/x64 和 Windows x64 上运行检查并构建；Windows 继续执行自定义目录安装、启动和卸载验证。自动化不操控用户的 Codex、不调用模型、不兑换真实重置机会。模拟故障和原生窗口测试不能覆盖所有用户的全屏、多显示器、系统更新或未来 Codex 版本。

发行签名状态未变：Mac 包没有 Developer ID 公证，Windows 包没有 Authenticode 签名。本次修复不消除系统发行者提示。

## English summary

Version 2.1.1 checks macOS window-server visibility for the exact overlay window and repairs missing panels without taking keyboard focus. Window tracking restarts after wake/unlock and keeps retrying with capped backoff instead of permanently stopping after several failures. Reset position also restarts tracking. The shared release retains official-service synchronization, Windows interaction fixes and custom installation directories. Existing settings and operation receipts are preserved; no real reset is used in testing.
