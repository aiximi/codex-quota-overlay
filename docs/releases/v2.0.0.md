# 2.0.0 · 首个公开跨平台版本

发布日期：**2026-10-11（Asia/Shanghai）**。发布标签：`v2.0.0`。

[下载中心](https://github.com/aiximi/codex-quota-overlay/blob/main/DOWNLOADS.md) · [全部版本与变化](https://github.com/aiximi/codex-quota-overlay/blob/main/docs/VERSIONS.md) · [此版本发布文件](https://github.com/aiximi/codex-quota-overlay/releases/tag/v2.0.0)

这是项目第一个公开发行版，提供 macOS 13+ Apple Silicon、macOS 13+ Intel，以及 Windows 10/11 x64 的共享 Electron/TypeScript 应用。macOS 提供 DMG 和 ZIP，Windows 提供安装版和便携版。

Windows 后续发布了专用修复版 [2.0.1](https://github.com/aiximi/codex-quota-overlay/blob/main/docs/releases/windows-v2.0.1.md)。macOS 继续使用本次发布的 2.0.0 文件；请通过下载中心选择各系统的版本。

## 更新内容

- Codex 位于前台时显示浮层；收起为 `276 × 42` 胶囊，展开查看详情，使用独立拖动柄调整位置。
- 显示账号实际返回的额度周期、剩余百分比、自然重置日期与倒计时，不预设所有账号都有相同限额。
- 每条重置机会分别显示到期日期与操作按钮；再次确认后才会消耗，请求互斥，结果不明确时不自动重试。
- 显示额外额度，以及尽力从官方账号接口获取的订阅续费/到期日期；支持按账号手动记录并标注来源。
- 提供中文、英文、托盘/菜单栏设置、可选登录启动与完全离线的示例预览。
- 公开分层源码、测试、IDEA 运行配置、构建流程，以及开发者可选的 Git 自动同步。发行应用不会自动启用 Git 同步。

## 安装与迁移

先安装官方 Codex 并使用受支持的 ChatGPT 文件登录。下载对应架构的文件，并对照 [本版本 SHA256SUMS.txt](https://github.com/aiximi/codex-quota-overlay/releases/download/v2.0.0/SHA256SUMS.txt) 校验。

macOS 打开 DMG，将应用拖到 Applications；Windows 安装版在向导中选择有写权限的目录，例如 `D:\Apps\Codex Quota Overlay`。Windows 便携版无需安装，放到所需盘符即可；用户数据仍保存在 `%APPDATA%\Codex Quota Overlay\`。自定义安装目录在此版本已经支持。

如果运行过本地原型或其他版本，请先通过菜单栏/托盘退出旧程序，再启动新版，避免两个浮层同时运行。详细步骤见 [安装与使用](https://github.com/aiximi/codex-quota-overlay/blob/main/docs/USAGE.md)。

## 验证范围与已知限制

发布经过类型、格式、离线单元测试、Electron 界面测试，以及 macOS arm64/x64、Windows x64 的 CI 打包检查。macOS 前台窗口跟随另有本地验证。预览和自动化测试使用示例数据，**没有兑换真实重置机会**。这些检查不代表已经在所有真实 Codex 版本、多屏或高 DPI 桌面完成手工验证。

2.0.0 的 Windows 版本后续发现了点击/键盘焦点、与 Codex 的窗口关联以及部分 CLI 额度查询问题；修复说明见 [Windows 2.0.1](https://github.com/aiximi/codex-quota-overlay/blob/main/docs/releases/windows-v2.0.1.md)。保留旧包用于历史追溯，Windows 使用者应优先选择修复版。

macOS 包未经过 Apple Developer ID 公证，Windows 包未经过 Authenticode 签名。SmartScreen 的“未识别的应用”可能在安装向导前出现；未签名和新文件信誉不足可能触发提示，签名也不能保证未来新文件完全没有提示。“未识别”本身不是病毒检测结论。核对来源和校验值后，用户可在系统提供入口时自行决定使用单应用允许操作；企业策略或 Smart App Control 阻止时，请联系管理员，**不要关闭全局保护**。参见 [Microsoft 的 SmartScreen 说明](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)。

仅支持可读取的 ChatGPT 文件登录；仅钥匙串凭证、API key 和自定义供应商可能不可用。订阅日期接口不是稳定公开 API，无法获取时可手动填写。没有自动更新器，Linux 暂无窗口跟随支持。

## English summary

Released on **October 11, 2026 (Asia/Shanghai)** as `v2.0.0`: the first public macOS Apple Silicon, Intel Mac and Windows x64 release. It includes quota windows, reset countdowns and credit expiration dates, confirmed reset redemption, subscription dates, Chinese/English settings, tray controls and offline preview.

Windows users should use the subsequent [Windows 2.0.1 patch](https://github.com/aiximi/codex-quota-overlay/blob/main/docs/releases/windows-v2.0.1.md); macOS stays on these 2.0.0 packages. Quit any old overlay before installing. Custom Windows installation folders were already supported in this release, and portable user data stays in `%APPDATA%\Codex Quota Overlay\`.

Validation used offline fixtures and CI builds; no real reset credit was redeemed. CI does not prove compatibility with every desktop, monitor or DPI configuration. Builds are not Apple Developer ID notarized or Windows Authenticode signed. Keep global security protections enabled and follow the [installation guide](https://github.com/aiximi/codex-quota-overlay/blob/main/docs/USAGE.md) for publisher warnings and supported login requirements.
