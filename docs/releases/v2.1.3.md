# 2.1.3 · macOS 桌面与全屏空间切换后的浮窗恢复

发布标签：`v2.1.3`。统一提供 macOS Apple Silicon、Intel 和 Windows x64 安装包。

[下载中心](https://github.com/aiximi/codex-quota-overlay/blob/main/DOWNLOADS.md) · [全部版本与变化](https://github.com/aiximi/codex-quota-overlay/blob/main/docs/VERSIONS.md) · [此版本发布文件](https://github.com/aiximi/codex-quota-overlay/releases/tag/v2.1.3)

## 更新内容

- 修复 macOS 桌面/全屏空间切换期间的可见性误判。系统的 `onscreen` 标记不再单独作为成功显示的依据；同时检查浮窗的实际矩形是否完整位于 Codex 窗口和物理显示器的交集内，允许少量像素舍入误差。
- 当浮窗滑到屏幕外、只剩边缘或显示位置失效时，恢复流程重新设置目标位置，即使 Electron 缓存的位置看起来已经正确。
- 连续确认浮窗不可见超过 5 秒时重建原生浮窗并重新绑定跟随助手，保留设置与界面状态；重建之间至少间隔 30 秒，避免反复闪烁。
- 只用最新窗口跟随消息触发原生恢复，额度更新和展开/收起不再重复使用旧的不可见状态。
- 保留切到 Codex 显示、切到其他应用隐藏的规则，以及 2.1.2 的浮窗点击和设置交互关联。Windows 行为不变，继续提供同版本安装版和便携版。

## 验证与范围

新增实际 Electron 测试窗口的回归：模拟原生位置在屏幕边缘、缓存位置正常的情况，验证重新定位且不抢输入焦点。原生测试覆盖屏幕外的 `onscreen=true`、边缘裁切、Codex 窗口范围、舍入误差和左侧副屏坐标；既有点击、设置、窗口跟随测试继续执行。

测试使用离线窗口和模拟系统观察，不兑换真实重置机会。发布流程在 Mac 两种架构和 Windows 上检查及构建；Windows 保留安装目录、启动和卸载验证。这些检查不能覆盖所有桌面、系统版本和显示器组合。

## 安装与迁移

先退出旧浮窗，再替换应用或运行新版安装包。设置和重置操作记录保留。切换到 Codex 后显示浮窗，切到无关应用或 Codex 不可见时隐藏；桌面切换动画期间可能短暂隐藏，窗口稳定后恢复。

当前没有应用自动更新器。签名状态未变：Mac 包没有 Developer ID 公证，Windows 包没有 Authenticode 签名。

## English summary

Version 2.1.3 validates macOS overlay geometry against the visible Codex/display intersection instead of trusting the WindowServer onscreen flag alone. Recovery reapplies the intended bounds even when Electron's cached bounds match. Only fresh native observations trigger repair; quota and UI updates do not replay an old invisible state. Existing Codex foreground following and click handling remain, with shared downloads for macOS and Windows.
