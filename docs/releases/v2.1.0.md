# 2.1.0 · 官方数据同步与状态准确性

发布标签：`v2.1.0`。提供 macOS Apple Silicon、Intel 和 Windows x64 版本。

[下载中心](https://github.com/aiximi/codex-quota-overlay/blob/main/DOWNLOADS.md) · [全部版本与变化](https://github.com/aiximi/codex-quota-overlay/blob/main/docs/VERSIONS.md) · [此版本发布文件](https://github.com/aiximi/codex-quota-overlay/releases/tag/v2.1.0)

## 更新内容

- 前台默认每 15 秒读取官方额度；返回 Codex、系统唤醒和额度周期到期时触发重新核对。失败或数据过时时明确标识，倒计时结束不代表额度已经恢复。
- 额度响应校验当前账号，只读取 Codex 对应的额度分组。缺失值显示未知，不当成零、无限或可继续使用。
- macOS 和 Windows 都先显示额度，再独立查询订阅日期，避免慢订阅接口阻塞额度刷新。
- 官方订阅日期优先于手动参考；缓存、人工记录及最后确认时间明确区分。账号切换后清除上一账号的显示。
- 主动请求完整的重置机会明细。旧版 CLI 明确拒绝参数格式时，仅对只读查询回退到旧格式；兑换重置机会仍不会自动重试。
- 保留 Windows 2.0.1 的点击、窗口跟随、原生 CLI 自动发现和自定义安装盘符功能。

## 数据一致性的范围

浮窗使用安装在本机的 Codex 官方 `app-server`，不修改 Codex，也不读取聊天内容。它周期性查询官方服务，并不是官方窗口的逐帧镜像。网络延迟、官方缓存、用户设置的刷新间隔都会影响两次显示之间的时差；界面显示最近确认状态，不承诺零延迟。

额度可用性以官方返回为准，不从百分比或倒计时推测恢复。重置明细未返回时显示未知；订阅接口不可用时保留明确标记的上次记录或手动参考，不伪造官方日期。当前认证适配器仍要求受支持的 ChatGPT 文件登录。

## 安装与迁移

先退出旧浮窗，再从统一下载中心选择本系统安装包。macOS 替换 Applications 中的应用；Windows 安装程序可选择安装目录，便携版直接替换 EXE。已有 Electron 版本的设置和重置操作记录保留，**不要删除未确认重置记录来尝试另一条机会**。早期 Swift 本地原型需要停止其旧启动项，避免同时运行两个浮窗。

## 验证范围

本版本的发布流程检查类型、格式、核心行为和离线 Electron 交互，在 macOS arm64/x64 与 Windows x64 构建安装包；Windows 还运行自定义目录安装及启动检查。离线测试覆盖参数兼容、账号不匹配、未知值、刷新状态和订阅响应顺序。自动化使用模拟数据，未消耗真实重置机会。

本地在线核对使用 Codex 26.1027.61615；不代表所有未来 Codex 版本、网络环境或多屏配置已经验证。Mac 包仍未经过 Developer ID 公证，Windows 包仍未经过 Authenticode 签名；本版本未改变系统发行者提示。

## English summary

Version 2.1.0 brings the shared macOS and Windows app closer to the official account state: a 15-second default foreground refresh, refresh on return and wake, response-account validation, explicit unknown/stale states, and nonblocking subscription requests. Official subscription dates take precedence over manual references. Read-only requests can fall back to the older parameter format; reset redemption never retries automatically.

This is periodic official-service synchronization, not an instantaneous mirror of the Codex UI. Existing operation receipts are preserved. Quit the previous overlay before installing, and keep global operating-system security protections enabled.
