# 2.1.2 · 修复 macOS 点击浮窗后消失

发布标签：`v2.1.2`。同时提供 macOS Apple Silicon、Intel 和 Windows x64 安装包。

[下载中心](https://github.com/aiximi/codex-quota-overlay/blob/main/DOWNLOADS.md) · [全部版本与变化](https://github.com/aiximi/codex-quota-overlay/blob/main/docs/VERSIONS.md) · [此版本发布文件](https://github.com/aiximi/codex-quota-overlay/releases/tag/v2.1.2)

## 更新内容

- 修复 macOS 点击浮窗、打开设置后，因前台进程变为浮窗自身而隐藏的问题。现在交互期间保留此前已确认的 Codex 窗口关联，继续跟随其位置。
- 关联同时核对 Codex 进程、启动时间、具体窗口 ID 和当前可见性。切换其他应用、Codex 隐藏或最小化、关闭原窗口后清除关联；单独打开浮窗设置不会凭空显示旧窗口上的浮层。
- 新增直接运行生产版 Swift 窗口选择逻辑的回归测试，覆盖连续交互、设置、移动、切换应用、最小化、关闭和进程/窗口身份变化。补齐此前离线预览测试没有启用窗口跟随的覆盖缺口。
- 保留 2.1.1 的原生可见性修复、唤醒恢复和跟随助手重试。Windows 功能与 2.1.1 相同，继续提供同版本的安装版与便携版。

## 更新方式

退出旧浮窗后安装新版。macOS 替换 Applications 中的应用；Windows 运行新安装包或替换便携 EXE。设置与重置操作记录保留，不需要退出或重新登录 Codex。更新本身不会兑换重置机会。

## 验证范围

原生窗口选择测试使用模拟的系统观察结果执行生产逻辑；离线 Electron 测试检查展开、收起、设置及实际窗口恢复。发布流程在 Mac 两种架构与 Windows 上运行检查，Windows 保留自定义目录安装验证。自动化不操控用户的 Codex，也不兑换真实重置机会。

这些检查不代表所有系统、桌面切换和显示器组合均已验证。发行签名状态未变：macOS 尚无 Developer ID 公证，Windows 尚无 Authenticode 签名。

## English summary

Version 2.1.2 fixes macOS overlays disappearing when interaction brings the overlay or its Settings application to the foreground. The helper retains a previously verified Codex window, revalidates its process, launch time, exact window identity and visibility, and clears it when an unrelated application takes foreground or the host becomes unavailable. Production Swift policy tests cover this tracking path, which offline preview tests did not exercise. Windows behavior is unchanged; both platforms remain available in the shared release.
