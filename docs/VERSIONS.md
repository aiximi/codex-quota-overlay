## 每次发行具体改了什么

### 2.1.3 · Windows 10/11 · x64、macOS 13+ · Apple Silicon、macOS 13+ · Intel

**发布日期：2026-11-11** · [完整更新说明](https://github.com/aiximi/codex-quota-overlay/blob/main/docs/releases/v2.1.3.md) · [原始发行与全部附件](https://github.com/aiximi/codex-quota-overlay/releases/tag/v2.1.3)

- 修复 macOS 桌面/全屏空间切换期间的可见性误判。系统的 `onscreen` 标记不再单独作为成功显示的依据；同时检查浮窗的实际矩形是否完整位于 Codex 窗口和物理显示器的交集内，允许少量像素舍入误差。
- 当浮窗滑到屏幕外、只剩边缘或显示位置失效时，恢复流程重新设置目标位置，即使 Electron 缓存的位置看起来已经正确。
- 连续确认浮窗不可见超过 5 秒时重建原生浮窗并重新绑定跟随助手，保留设置与界面状态；重建之间至少间隔 30 秒，避免反复闪烁。
- 只用最新窗口跟随消息触发原生恢复，额度更新和展开/收起不再重复使用旧的不可见状态。
- 保留切到 Codex 显示、切到其他应用隐藏的规则，以及 2.1.2 的浮窗点击和设置交互关联。Windows 行为不变，继续提供同版本安装版和便携版。

### 2.1.2 · Windows 10/11 · x64、macOS 13+ · Apple Silicon、macOS 13+ · Intel

**发布日期：2026-11-11** · [完整更新说明](https://github.com/aiximi/codex-quota-overlay/blob/main/docs/releases/v2.1.2.md) · [原始发行与全部附件](https://github.com/aiximi/codex-quota-overlay/releases/tag/v2.1.2)

- 修复 macOS 点击浮窗、打开设置后，因前台进程变为浮窗自身而隐藏的问题。现在交互期间保留此前已确认的 Codex 窗口关联，继续跟随其位置。
- 关联同时核对 Codex 进程、启动时间、具体窗口 ID 和当前可见性。切换其他应用、Codex 隐藏或最小化、关闭原窗口后清除关联；单独打开浮窗设置不会凭空显示旧窗口上的浮层。
- 新增直接运行生产版 Swift 窗口选择逻辑的回归测试，覆盖连续交互、设置、移动、切换应用、最小化、关闭和进程/窗口身份变化。补齐此前离线预览测试没有启用窗口跟随的覆盖缺口。
- 保留 2.1.1 的原生可见性修复、唤醒恢复和跟随助手重试。Windows 功能与 2.1.1 相同，继续提供同版本的安装版与便携版。

### 2.1.1 · Windows 10/11 · x64、macOS 13+ · Apple Silicon、macOS 13+ · Intel

**发布日期：2026-11-11** · [完整更新说明](https://github.com/aiximi/codex-quota-overlay/blob/main/docs/releases/v2.1.1.md) · [原始发行与全部附件](https://github.com/aiximi/codex-quota-overlay/releases/tag/v2.1.1)

- 修复 macOS 浮窗进程仍在运行、Codex 已在前台但浮窗没有出现在当前桌面的情况。原生助手按浮窗的窗口 ID 和进程核对实际可见性，不再仅依赖 Electron 的可见标志；发现不一致时重新显示，保持 Codex 输入焦点。
- 在系统唤醒、解锁后重启窗口跟随，先清除旧位置，再根据当前前台窗口恢复显示，避免沿用休眠前的窗口状态。
- 修复窗口跟随助手累计失败几次后永久停止的问题。macOS 和 Windows 均持续自动重连，失败时逐步退避到最长 30 秒，恢复稳定后回到短重试间隔。
- 菜单栏/托盘和设置中的“恢复浮层位置”同时重新启动窗口跟随。只会在重新确认 Codex 窗口有效时恢复显示。
- 保留 2.1.0 的官方额度、订阅及重置明细同步，以及 Windows 的点击、自定义安装盘符和便携版支持；本次没有改变重置兑换逻辑。

### 2.1.0 · Windows 10/11 · x64、macOS 13+ · Apple Silicon、macOS 13+ · Intel

**发布日期：2026-11-06** · [完整更新说明](https://github.com/aiximi/codex-quota-overlay/blob/main/docs/releases/v2.1.0.md) · [原始发行与全部附件](https://github.com/aiximi/codex-quota-overlay/releases/tag/v2.1.0)

- 前台默认每 15 秒读取官方额度；返回 Codex、系统唤醒和额度周期到期时触发重新核对。失败或数据过时时明确标识，倒计时结束不代表额度已经恢复。
- 额度响应校验当前账号，只读取 Codex 对应的额度分组。缺失值显示未知，不当成零、无限或可继续使用。
- macOS 和 Windows 都先显示额度，再独立查询订阅日期，避免慢订阅接口阻塞额度刷新。
- 官方订阅日期优先于手动参考；缓存、人工记录及最后确认时间明确区分。账号切换后清除上一账号的显示。
- 主动请求完整的重置机会明细。旧版 CLI 明确拒绝参数格式时，仅对只读查询回退到旧格式；兑换重置机会仍不会自动重试。
- 保留 Windows 2.0.1 的点击、窗口跟随、原生 CLI 自动发现和自定义安装盘符功能。

### 2.0.1 · Windows 10/11 · x64

**发布日期：2026-10-12** · [完整更新说明](https://github.com/aiximi/codex-quota-overlay/blob/main/docs/releases/windows-v2.0.1.md) · [原始发行与全部附件](https://github.com/aiximi/codex-quota-overlay/releases/tag/windows-v2.0.1)

- **面板能显示却无法正常点击或输入。** Windows 浮层现在可在点击时获得原生窗口焦点；刚出现时仍使用不激活的显示方式，避免抢占 Codex 正在使用的键盘焦点。
- **点击浮层或设置后，窗口跟随失效。** 与浮层交互期间保留最后一个已确认的 Codex 窗口关联，并持续检查它是否有效。切换到其他应用、最小化或关闭 Codex 后仍会隐藏，失效的窗口关联会被清除。
- **找不到 CLI，或额度一直显示 `—`。** 自动查找 `%LOCALAPPDATA%\OpenAI\Codex\bin` 下受管理的版本目录与原生 `codex.exe`，避免选中无法独立运行的 MSIX 资源程序。Windows 额度查询改用其 CLI 支持的无参数请求；macOS 的请求方式保持原样。
- **额度被订阅查询拖延。** Windows CLI 返回用量后立即显示；可选的订阅日期请求较慢时，不再延迟已有用量。
- **拖动不流畅。** 拖动位置先保存在内存中，在移动完成或短暂静止后写入设置，避免每次鼠标移动都同步写盘。

同一源码版本还整理了 IDEA 运行配置与本地格式化入口，改进 Windows 开发者 Git 同步的隐藏启动、日志与运行时路径处理。发行应用不会自动开启开发者 Git 同步。

- 提供中文、英文、托盘/菜单栏设置、可选登录启动与完全离线的示例预览。
- 公开分层源码、测试、IDEA 运行配置、构建流程，以及开发者可选的 Git 自动同步。发行应用不会自动启用 Git 同步。

## 历史版本保留规则

- 已公开的版本标签、安装包和下载地址保留；修复通过新版本发布。
- 单系统更新只推进对应系统的最新版本，其他系统继续显示各自的最新稳定版。
- 草稿和预发行版本不进入稳定版下载推荐；GitHub 自动生成的 Source code 文件是源码，不是安装包。
- 本页展示公开发行的桌面安装包。早期仅本地使用的原型未公开分发，不提供下载。
